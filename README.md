# Portfolio de Máximo Mayandes

Trabajo Práctico Integrador de Desarrollo Web: **Mi Portfolio Web Profesional en GitHub Pages**.

## Archivos
- `index.html` — presentación, proyectos, habilidades y ChangaYa.
- `css/estilos.css` — diseño editorial, responsivo, paletas de colores.
- `js/interacciones.js` — cambio de paleta y botón de copiar enlace.
- `FICHA_ENTREGA.txt` — respuestas del trabajo práctico, con espacio para las dos URL de GitHub.

## Publicación paso a paso
1. Ingresar a https://github.com con la cuenta de Máximo.
2. Crear repositorio público `portfolio-maximo`.
3. Subir **el contenido** de esta carpeta, no la carpeta contenedora ni el ZIP. `index.html` debe quedar en la raíz; `css/` y `js/` deben mantener sus nombres.
4. Abrir `Settings → Pages`, elegir `Deploy from a branch`, `main` y `/(root)`, luego guardar.
5. Cuando aparezca el enlace público, abrirlo y verificar estilos, navegación y botones.
6. Completar las dos URL en la ficha. La URL será `https://USUARIO.github.io/portfolio-maximo/`, sustituyendo USUARIO por el nombre real de GitHub.

**Importante:** el sitio es estático. Muestra una descripción conceptual del proyecto grupal ChangaYa; no ejecuta la aplicación móvil ni un servidor.
